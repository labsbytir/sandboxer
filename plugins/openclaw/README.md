# Sandboxer for OpenClaw

Native tools for Sandboxer environments, deployments, Kubernetes and reports.
Requires a running local Sandboxer companion and its token in
`SANDBOXER_SERVICE_TOKEN`; port defaults to 47381.

See [installation and configuration](https://github.com/labsbytir/sandboxer/blob/staging/docs/agent-plugins.md).
The action tool is optional: enable `sandboxer_action` in `tools.allow`.
This preview targets OpenClaw 2026.10.4; real host validation is pending.
